# Checklist de diff y dependencias

## Alcance del diff

- [ ] Solo cambiaron archivos autorizados.
- [ ] No aparecieron archivos de configuración inesperados.
- [ ] No se reformateó código no relacionado.
- [ ] El cambio corresponde a una sola intención.
- [ ] No se eliminaron pruebas ni validaciones sin justificación.

## Comportamiento

- [ ] Se conservan firmas públicas.
- [ ] Se conserva la forma de la salida.
- [ ] Se conservan errores acordados.
- [ ] No aparecieron efectos secundarios nuevos.
- [ ] Se ejecutaron casos anteriores.
- [ ] Los criterios nuevos poseen pruebas.

## Dependencias

- [ ] La dependencia existe en un registro oficial.
- [ ] La versión es compatible.
- [ ] La licencia fue revisada.
- [ ] El proyecto mantiene actividad.
- [ ] La biblioteca estándar no resuelve mejor la tarea.
- [ ] La dependencia ya existe o su incorporación está justificada.
- [ ] No requiere credenciales ni servicios no autorizados.

## Recuperación

- [ ] Existe un commit o copia previa.
- [ ] El diff fue guardado.
- [ ] Sé qué comando o copia utilizar para volver atrás.
- [ ] La ruta fue verificada antes de restaurar.
