# Checklist de seguridad y validación

## Antes de compartir contexto

- [ ] La tarea está delimitada.
- [ ] Seleccioné únicamente el fragmento necesario.
- [ ] Eliminé contraseñas, claves, tokens y cookies.
- [ ] Eliminé datos personales y empresariales reales.
- [ ] No incluí archivos `.env` ni claves privadas.
- [ ] Tengo autorización para compartir el código seleccionado.
- [ ] Revisé los controles y términos vigentes de la herramienta cuando corresponde.
- [ ] Puedo realizar la tarea con datos ficticios.

## Antes de copiar o aceptar código

- [ ] Leí toda la propuesta.
- [ ] Puedo explicar cada parte.
- [ ] No agregó dependencias innecesarias.
- [ ] No inventó funciones, archivos o versiones.
- [ ] No modificó requisitos sin indicarlo.
- [ ] No contiene comandos destructivos.
- [ ] No oculta errores mediante capturas demasiado generales.
- [ ] El cambio es pequeño y reversible.

## Antes de integrar

- [ ] El código se ejecuta en un entorno controlado.
- [ ] Probé un caso normal.
- [ ] Probé cada límite importante.
- [ ] Probé entradas inválidas.
- [ ] Comparé resultados esperados y reales.
- [ ] Consulté documentación oficial cuando la versión importa.
- [ ] Revisé licencias y procedencia cuando corresponde.
- [ ] Registré la decisión en la bitácora.

## Si se compartió una credencial por accidente

- [ ] Detuve el uso de la credencial.
- [ ] La revoqué o roté.
- [ ] Revisé registros de acceso.
- [ ] La eliminé del código y del historial correspondiente.
- [ ] Informé mediante el procedimiento aplicable.
